# Everest terrain textures

These textures are sourced from Poly Haven and distributed under CC0.

- `snow_02_*_2k.jpg` — Poly Haven `snow_02` (Rob Tuytel), used as close-range snow detail/albedo, normal, and roughness.
  Source: https://polyhaven.com/a/snow_02
- `snow_field_aerial_*_2k.jpg` — Poly Haven `snow_field_aerial` (Rob Tuytel), used for large-scale/macro snow variation. The source scan represents roughly 80 m.
  Source: https://polyhaven.com/a/snow_field_aerial
- `rocky_terrain_02_*_2k.jpg` — Poly Haven `rocky_terrain_02` (Amal Kumar), used for exposed steep terrain/rock variation. The source scan represents roughly 90 m.
  Source: https://polyhaven.com/a/rocky_terrain_02

License: CC0 / public domain dedication. See https://polyhaven.com/license

Unity import settings for these textures are applied by `Assets/Editor/EverestTextureImporter.cs`.
